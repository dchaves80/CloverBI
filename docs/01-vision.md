# 🍀 Clover BI - Visión

## ¿Qué es?

Clover BI es una plataforma que permite consultar bases de datos usando lenguaje natural y obtener dashboards automáticamente.

**Sin saber SQL. Sin armar gráficos manualmente. Solo preguntás.**

> 🍀 Powered by [Clovers Platform](../../Clovers/) - Nuestra infraestructura de agentes IA

---

## El Problema

Hoy, para obtener insights de datos necesitás:

- Saber SQL o depender de alguien que sepa
- Usar herramientas complejas (Tableau, Power BI, Metabase)
- Contratar analistas de datos
- Esperar días/semanas por un reporte

**Las pymes y equipos chicos quedan afuera.**

---

## La Solución

```
Usuario: "¿Cuánto vendimos en enero vs diciembre?"
         │
         ▼
    🍀 Clover Agent
         │
         ▼
📊 Dashboard con gráfico comparativo
```

1. Conectás tu base de datos (una vez)
2. Preguntás lo que quieras en español
3. **Clover Agent** interpreta, consulta, y arma el gráfico
4. Listo

## Diferencial

| Competencia | Problema | Clover BI |
|-------------|----------|-----------|
| Power BI / Tableau | Caros, complejos | Accesible, simple |
| Metabase | Requiere conocer datos | Lenguaje natural |
| ChatGPT + datos | Genérico, no integrado | Especializado en BI |

**Clover BI = Simplicidad + Clover Agent + Precio accesible**
